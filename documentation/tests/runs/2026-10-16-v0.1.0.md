## Fixed on the way

Harness and script bugs found by these runs, all fixed before the green runs above:

- The regression's prerequisite check required the test build, which the regression only builds in
  its next step; a fresh clone failed there. `doctor.sh --before-build` skips that one check.
- A run interrupted before `onComplete` left Appium on port 4723, and the next run hung on it.
- The runner's end-of-spec `deleteSession()` crashed a spec that had quit the app.
- ⌘W was synthesised to whatever had focus; it is now aimed at the window.
- A retry overwrote the first attempt's failure report.
- A test build left open from another checkout took the single-instance lock and port 4445; the
  doctor and the cleanup now find a test build from any checkout.
- Appium finds the app through Launch Services, where a directly spawned bundle is not registered
  and another checkout's can win the lookup; the harness now registers only this checkout's bundle.
  Targeting the bundle by path instead was tried and broke ⌘W/⌘Q, so it was reverted.
- A checkout under `/tmp` cannot run e2e at all: Launch Services will not resolve an app flagged
  `in-temp-dir`. The doctor now refuses one; the fresh-clone check was re-run under the home folder.
