# TRAY-006 — [OS tray][Appearance] Switch macOS to Dark appearance -> the icon inverts and stays legible

| | |

## Purpose

The icon is a template image (`icon_as_template(true)`), so macOS should recolour it. A non-template icon turns into a dark blob on a dark menu bar.

## Preconditions

- A release bundle is installed in `/Applications` and carries no debug entitlements. Login items, notifications and the activation-policy flip behave differently for an unbundled `tauri dev` binary, so never run this against one. From the repo root:

  ```bash
  npm run tauri build
  rm -rf "/Applications/jira-to-qa-portal.app"
  cp -R "src-tauri/target/release/bundle/macos/jira-to-qa-portal.app" /Applications/
  codesign -d --entitlements - /Applications/jira-to-qa-portal.app 2>&1 | tail -2
  ```

  The last command must print a single `Executable=…` line and no entitlements dict. Anything else means the bundle was re-signed for a performance session; rebuild it.
- The app is running, launched by hand (not by the login item):

  ```bash
  open -a "/Applications/jira-to-qa-portal.app"
  APP_PID=$(pgrep -f "jira-to-qa-portal.app/Contents/MacOS" | head -1); echo "APP_PID=$APP_PID"
  ```

## Steps

1. System Settings → Appearance → **Dark**.
2. Look at the tray icon.

## Expected result

- The icon is drawn light on the dark menu bar. It does not disappear and does not become a dark blob.
